# Java Training

Dépôt regroupant mes exercices pratiques réalisés dans le cadre de mon apprentissage autodidacte de Java et de ma reconversion vers la QA / le test logiciel.

## Objectif

Consolider mes bases en programmation et en algorithmique avant d'aborder plus spécifiquement les outils et frameworks de QA Automation.

## Notions travaillées

- Conditions et boucles
- Tableaux 1D et 2D
- ArrayList
- Chaînes de caractères
- Parcours, recherches et comparaisons de données
- Calculs, compteurs et séries
- Programmation orientée objet
- Gestion des exceptions
- Débogage
- Fichiers texte / CSV
- Premières notions d'interfaces Swing

## Environnement

- Java
- Eclipse

Ce dépôt est un espace d'apprentissage : les exercices évoluent progressivement avec ma pratique.
